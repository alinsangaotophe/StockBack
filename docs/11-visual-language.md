# Own visual language

Own uses an expressive consumer-product direction inspired by Material 3 Expressive principles, adapted to the web. The core visual story is purchase → cashback → company token. This replaces the earlier editorial serif direction.

## System

- DM Sans provides a modern interface voice. Headlines use weight 600 and tight tracking; monetary values use clear, tabular numerals. Explanatory copy remains quieter.
- Warm white (#fffbff), lavender surfaces (#f7f2fa / #f0eaf5), and violet primary actions (#6750d8) establish the application identity, inspired by the Material 3 website. Dark charcoal text and muted purple support reading. Brand examples use mint for Starbucks, pale blue for Apple, butter yellow for Nike and peach for Tesla. Cashback badges use a restrained yellow accent.
- Shapes have roles: 16px controls, 22–28px content groups, a 32px hero container. The reward tile has an asymmetric corner to distinguish it from a product surface.
- The purchase, cashback and ownership steps increase in tonal emphasis. Brand selection updates the product, amount and destination together.
- Short entrance transitions reinforce that relationship without continuous animation. Reduced-motion preferences disable these transitions and entrance effects.
- Shop surfaces, asset icons, account summaries and checkout confirmation use the same rounded, tonal language. Primary actions stay violet across brands, including hover and focus states.
- Demo, stock-backing and illustrative-rate disclosures remain visible. These visuals do not imply actual share ownership on Devnet.

Fonts are loaded from Google Fonts with local sans-serif fallbacks. No Wear-specific curved text or circular screen geometry is copied.
