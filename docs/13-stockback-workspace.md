# StockBack — 三项功能的资产工作台

更新：2026-09-15。本文是当前前端范围，取代旧版商城、充值、购物和奖励领取页面设计。

## 产品范围与交互

1. **账户与 U 卡**：Google 登录入口 → 账户 → 绑定 U 卡。当前真实身份与卡服务未提供，Google 按钮明确为不可用；独立的演示账户入口进入绑卡流程。只输入样例末四位并确认，不收集完整卡号或 CVV。账户页支持查看、解绑、重新绑定与退出演示会话。
2. **消费、收益与持仓**：首页展示资产总额、当月已结算奖励、四种股票代币与最近消费。Activity 支持商户/股票搜索、结算状态筛选、空结果恢复和详情。消费详情列出金额、返奖率、奖励美元金额、股票数量和结算状态；待结算奖励不进入可转出余额。
3. **提现与 Swap**：从总资产或具体持仓进入弹窗；选择代币、数量，提现额外填写 Solana 钱包地址。金额校验、Max、可用余额、费用、复核、返回编辑、确认、反馈与流水构成完整闭环。Swap 将股票换为 USDC。解绑卡不会锁定已经获得的资产。

主导航只保留 Overview / Activity / Account；移动端对应底部三项导航。延续现有英文产品语言。

## 当前实现边界

- 静态 Next.js export；没有账户后端、Google OAuth Client ID、发卡平台接口、消费 webhook、实际股票发行方或真实交易路由。Google 认证、真实绑卡、链上提现与 Swap 尚未接入。
- 新界面不调用旧版奖励合约，也不要求浏览器钱包签名。不发生链上广播。
- `lib/stockback.ts` 是样例数据和纯演示账本。股票符号与价格是 UI fixtures，不对应仓库旧 Devnet 部署文件，不代表实际持仓或法律意义上的股票所有权。
- 初始资产为 653 USD 的样例累计余额，消费列表只是一段近期样例，不是该余额的全部来源。9 月已结算奖励 30.97 USD，历史样例已结算 32.27 USD，待结算 0.25 USD。
- 演示 Swap 费率 0.30%，以六位代币精度计算到账；这是固定样例报价。提现费为模拟 0 SOL。每次确认产生一条本地流水，刷新保留。
- `stockback-workspace-v2` 存储单个本地演示账户。它不是鉴权边界，也不是实际资金账本。历史 wallet-scoped storage 不迁移，旧链上数据不修改。

## 真实接入的具体依赖

1. Google Client ID、允许域名和受信任账户后端；后端验证身份并维护服务端会话，不能信任前端 signedIn 标记。
2. 明确 U 卡发卡平台、其托管绑卡页面/SDK 和去重的消费事件接口；只接收 tokenized card reference。
3. 真实股票代币 mint、发行方/托管模型、奖励结算与冻结规则；余额应由可核对账本与链上状态生成。
4. 提现的授权/签名模型、费用估算、幂等提交与确认追踪；Swap 需实时路由、报价有效期、最小到账、滑点及模拟。这些都不可用样例状态替代。
